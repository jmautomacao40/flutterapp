1. Escopo

Esta Política de Privacidade descreve como o aplicativo Primedge (“Aplicativo”) trata dados durante o uso. O Aplicativo é utilizado para coleta e visualização de dados industriais (ex.: produção, status de máquina, sensores e indicadores), com foco em operações e rotinas de Indústria 4.0.

2. Dados que tratamos

2.1. Dados técnicos industriais (não pessoais)

  • Dados de produção (quantidade, tempos, status de máquina, contadores);
  • Leituras de sensores (corrente, tensão, sinais digitais, etc.);
  • Eventos de operação, alarmes técnicos e dados para manutenção/diagnóstico.

2.2. Dados de conta (quando aplicável)

Se o ambiente exigir autenticação, o Aplicativo pode tratar dados como nome, e-mail corporativo e perfil de acesso (ex.: vendedor, admin, customer service), exclusivamente para controle de acesso, auditoria e operação do sistema.

2.3. Dados do dispositivo e logs

Para funcionamento e segurança, podem ser registrados dados técnicos como: modelo do dispositivo, versão do sistema, identificadores técnicos de sessão, erros e logs de sincronização. Esses dados não são utilizados para publicidade.

3. Permissões do aplicativo

O Aplicativo pode solicitar permissões do sistema operacional. Principais permissões e finalidades:

  • Câmera (android.permission.CAMERA): usada para leitura de QR Code/código de barras (ex.: identificação de máquinas, produtos, ordens ou documentos). O Aplicativo não grava vídeo nem tira fotos automaticamente, salvo se você iniciar uma captura.
  • Internet: para sincronização com servidor e carregamento de dados autorizados.
  • Arquivos/Armazenamento (quando aplicável): para salvar/abrir PDFs e relatórios gerados pelo Aplicativo.

4. Como usamos os dados

  • Monitoramento operacional e indicadores (ex.: performance, disponibilidade, qualidade);
  • Geração de relatórios e registros técnicos (ex.: PDFs de checklist, RFQ, visitas técnicas);
  • Sincronização com backend autorizado pela empresa/cliente;
  • Auditoria, segurança e prevenção de falhas.

5. Compartilhamento

Não vendemos dados e não compartilhamos informações com terceiros para fins de publicidade. Os dados podem ser acessados apenas por:

  • Usuários autorizados pela empresa/cliente (ex.: equipe de manutenção, supervisão, customer service);
  • Provedores técnicos necessários para hospedagem/infraestrutura (ex.: servidor/VPS), sob confidencialidade;
  • Autoridades competentes, quando exigido por lei.

6. Armazenamento, retenção e segurança

Os dados podem ser armazenados localmente no dispositivo (modo offline-first) e/ou em servidores configurados, conforme o ambiente de uso. Adotamos medidas técnicas e organizacionais para reduzir riscos de acesso indevido, incluindo autenticação, controle de acesso e criptografia em trânsito quando aplicável (HTTPS/TLS).

Retenção: mantemos os dados pelo tempo necessário para operação do sistema, auditoria e requisitos contratuais/legais. A empresa/cliente pode definir políticas internas de retenção.

7. Seus direitos (LGPD)

Quando houver dados pessoais (ex.: login corporativo), você pode solicitar: confirmação do tratamento, acesso, correção, anonimização, portabilidade (quando aplicável) e exclusão, respeitando obrigações legais e contratuais.

Solicitações podem ser feitas pelo e-mail: suporte@primedge.com.br

8. Crianças e adolescentes

Este Aplicativo não é direcionado a crianças e não foi projetado para coletar dados de menores de 13 anos.

9. Transferência internacional

Dependendo da infraestrutura contratada (ex.: VPS/serviços em nuvem), dados podem ser processados em servidores localizados fora do Brasil. Quando isso ocorrer, buscamos manter proteções adequadas conforme a LGPD.

10. Alterações nesta política

Podemos atualizar esta política periodicamente. A data no topo indica a versão mais recente. Recomendamos revisar este documento sempre que houver atualização do Aplicativo.
